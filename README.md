## 🧠 Overview

This project builds a Perplexity-style answer engine using:

- [Groq](https://www.groq.com/)
- [Mixtral](https://mistral.ai/news/mixtral-of-experts/)
- [Langchain.JS](https://js.langchain.com/docs/)
- [Brave Search](https://search.brave.com/)
- [Serper API](https://serper.dev/)
- [OpenAI](https://openai.com/)

It returns sources, answers, images, videos, and follow-up questions.

## ⚙️ Technologies Used

- **Next.js** – React framework for SSR and static sites
- **Tailwind CSS** – Utility-first CSS framework
- **Vercel AI SDK** – Streaming AI chat UI
- **Groq & Mixtral** – Query processing
- **Langchain.JS** – Text splitting and embeddings
- **Brave Search** – Privacy-focused search engine
- **Serper API** – Fetches video/image results
- **OpenAI Embeddings** – Vector representations
- **Cheerio** – HTML parsing
- **Ollama (Optional)** – Local inference
- **Upstash Redis & Semantic Cache (Optional)** – Rate limiting and caching
